# 安装与下载

公开安装包仍在验证，尚未上架飞牛应用中心。首个候选包按 x86 飞牛设备准备，最低 fnOS 版本以最终发布说明为准。

本仓库目前提供产品介绍、使用教程、版本说明和问题反馈，暂不提供可独立完成部署的公开安装包。

正式发布时，本页会补充：

- 支持的飞牛 fnOS 版本与设备架构。
- 应用中心入口或正式安装包下载地址。
- 首次安装、文件夹授权、字幕来源配置与升级说明。
- 完整的收费、试用及激活说明。现有方案提供 20 部影片的字幕补齐体验，额度用完后仍可扫描和查看已有字幕。

GitHub 自动生成的 **Source code** 压缩包只是本仓库文档的归档，不是 SubFlow FN 软件安装包。

安装说明发布后，再按[使用教程](使用教程.md)开始操作。
