# 安装与下载

## 当前状态

**0.1.146** 提供 x86 原生 FPK，内置运行组件，安装无需拉取 Docker 镜像。已在飞牛 NAS 上验证覆盖升级、服务启动和已有数据保留。公开下载及飞牛应用中心上架信息将在本页公布。

本仓库提供产品介绍、教程和问题反馈。GitHub 自动生成的 **Source code** 压缩包收录本仓库文档。飞牛安装需要单独的 FPK 文件。

## 已取得安装包

1. 在 x86 飞牛的「应用中心」选择「手动安装」，上传对应版本的 FPK。
2. 使用原安装位置覆盖升级，可继续使用已有设置、授权目录和任务记录。升级前请等待当前任务结束。
3. 从飞牛桌面打开 SubFlow FN。在飞牛应用设置中添加要使用的影片目录并保存授权，再在应用里选择扫描文件夹。
4. 按[使用教程](使用教程.md)配置目标语言和字幕来源，先在小范围内验证处理结果。

## 试用与激活

本应用含付费功能，可免费体验 20 部影片的字幕补齐。激活后可继续处理影片。体验额度用完后，仍可扫描、查看已有字幕和处理记录。付费与飞牛官方无关。
