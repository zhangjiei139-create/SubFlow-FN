# 常见问题

## 现在在哪里下载？

公开安装包准备中，尚未上架飞牛应用中心。当前仓库先提供介绍、教程与反馈入口。下载发布后将更新[安装与下载](安装与下载.md)。

## 搜到了候选，为什么没有保存？

候选仍需通过正文语言、格式和时间轴核验。影片剪辑、片源或发行版本不同，都可能导致不匹配。先查看详情或导出日志中的具体原因，再决定换版本、调整查询条件或导入其他 SRT。

## 自动处理没有补齐，下一步怎么做？

打开影片详情，先查看每种缺失语言的原因。可按具体搜索建议尝试片名、年份或 IMDb 编号；已经确认身份、但候选未通过同步核验时，优先寻找其他发行版本的字幕。手头有 SRT 时可以直接导入。

建议是否出现，取决于能否获得足够的身份及候选证据；不是每部影片都会产生新的可用搜索条件。

## 只补了一种语言，算完成了吗？

以你勾选的目标语言为准。详情会分别列出已有字幕和仍缺少的语言，单份字幕通过不代表所有目标都已完成。

## 为什么图片字幕显示“未完成校验”？

内嵌图片字幕的读取与识别可能触及预算上限。这种情况会明确标注未完成校验，并按已有字幕保留，不能据此理解为已经逐条检查通过。已有明确拒绝结果不会因预算耗尽而改为通过。

## 需要显卡或一直开着电脑吗？

FN 版的处理在飞牛设备上运行，采用串行任务，不要求显卡或常驻电脑。实际耗时取决于影片、字幕类型、网络和设备性能。

## 能自动翻译字幕吗？

当前 FN 版使用已有字幕及在线字幕来源，不运行本地 AI 翻译。

## 支持哪些影片？

当前主要支持 MKV 和常规 MP4 电影。不能据此认为已支持所有剧集、特别篇命名或复杂 MP4 结构；无法可靠确认的情况会保留具体处理原因。

## PC 和 FN 会同步任务吗？

当前没有提供两端任务、设置或字幕处理状态同步。商业授权方案及收费／试用说明尚未正式发布，以后续公告为准。

## 如何反馈才方便定位？

请提供应用版本、飞牛系统版本、影片名与年份、发行版本、缺少语言、具体操作，以及对应的错误提示或经过检查的日志片段。

不要公开 API Key、密码、激活码、访问令牌、完整私人访问地址或不希望公开的媒体路径。
