# SubFlow FN 使用教程

本教程按 0.1.94 预览版整理，从已经完成部署开始。公开安装包及安装步骤发布后，请先按[安装与下载](安装与下载.md)完成安装。

## 1. 打开应用

在已登录的飞牛电脑桌面或手机应用内打开 SubFlow FN，可直接进入媒体库，无需再次输入 SubFlow 管理密码。

通过独立 IP／端口直接访问时，仍使用 SubFlow 自身的管理密码。飞牛系统账号登录不受影响。

## 2. 设置语言与字幕来源

进入“设置”，选择需要补齐的目标语言。

在“字幕来源”中填入自己的 OpenSubtitles 或 SubDL API Key，测试连接，然后点击“保存设置”。可以只配置一个来源，也可以同时配置两个来源。

- OpenSubtitles：[API Key 入口](https://www.opensubtitles.com/consumers)
- SubDL：[API Key 入口](https://subdl.com/panel/api)

下载额度及访问规则以字幕站为准。没有配置在线来源时，仍可在影片详情导入自己的 SRT。

TMDB 用于可选的影片身份和搜索建议补查，不是普通字幕搜索、SRT 导入的必需项。公开发行版的配置方法将随安装说明提供。

## 3. 选择扫描方式

### 局部扫描

点击“局部扫描”→“选择文件夹”，添加需要处理的影片目录。范围包含子文件夹；需要更新信息时，点击“重新读取”。

确认影片和目标语言后，点击“开始处理”。列表中的片名搜索、状态筛选只改变显示，不缩小文件夹的处理范围。

### 全局扫描

切换到“全局扫描”，先确认页面列出的已授权存储位置。这里扫描的是应用已获得访问权限的位置，不会绕过飞牛授权。

| 按钮 | 操作 |
| --- | --- |
| 开始全局扫描 | 只扫描、更新影片与字幕信息 |
| 开始处理 | 对当前已扫描范围中符合条件的影片开始处理 |
| 扫描并处理 | 扫描成功后，自动开始处理待补齐影片 |

“扫描并处理”适合希望一次完成扫描和处理的情况。正常运行时，关闭页面后后台仍会继续；取消或扫描失败时不会自动接续处理。

第一次使用可以先选一个小目录，熟悉结果后再扩大范围。

## 4. 查看处理进度与结果

在媒体库打开影片详情，查看已有字幕、缺失语言、当前步骤及处理结果；也可进入“运行日志”查看批次和单片记录。

通过核验的新增字幕保存为影片旁的外挂文件，例如：

```text
Movie.2020.mkv
Movie.2020.zh-CN.srt
Movie.2020.en.srt
Movie.2020.de.srt
```

补字幕不会把字幕烧入画面。播放器是否支持发现或选择外挂字幕，取决于所用播放器；媒体库播放器尚未显示新字幕时，可刷新影片信息后重新打开。

## 5. 手动搜索字幕

自动没有达到目标时，在影片详情展开“手动搜索字幕”：

1. 核对片名和年份，选择这次要找的语言。片名栏也支持 IMDb 编号，如 `tt` 开头的影片编号。
2. 点击“搜索”，查看候选的发行版本。
3. 点击候选旁的“使用”，选中要尝试的版本。
4. 点击“处理”，程序才会下载、核验并保存。

“使用”只选中候选，不会立即下载。某个版本未通过时，先查看原因，再决定尝试其他版本。

如果详情提供了具体搜索建议，可点击“填入搜索条件”，核对可见条件后再点击“搜索”。填入条件本身不会修改影片文件名，也不会自动下载或保存字幕。

## 6. 导入自己的 SRT

在影片详情使用“导入字幕”，选择本地 SRT。程序会识别语言、核验时间轴，通过后保存外挂并更新状态；语言无法确定时会要求确认。

## 7. 设置每日处理

在“设置”中的“定时处理新片”选择目录和每日开始时间，然后保存。

该定时流程包含子文件夹，完成项会归入 `complete` 并保留子目录结构，未完成或仍在写入的影片留在原位置。建议为该流程单独安排待处理目录。

## 8. 反馈问题

可按[常见问题](常见问题.md)中的说明整理信息，再到仓库的 Issues 提交。公开反馈前，请检查截图和日志，去掉 API Key、密码、访问令牌、私人地址及不希望公开的路径。
