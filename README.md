# SubFlow FN

**让影片留在飞牛上，按需搜索、核验和补齐字幕。**

SubFlow FN 面向飞牛 fnOS 的电影媒体库，读取已有的内嵌字幕和外挂字幕，按所选语言寻找缺失字幕，核验通过后保存为影片旁的外挂 SRT。处理在 FN 上运行，可从飞牛电脑桌面和手机应用入口查看进度与结果。

当前功能基线为 **0.1.97 预览版**，主要支持 MKV、常规 MP4 电影，以及中文、英文、德文字幕。

## 可以做什么

- **查看已有字幕**：在影片详情查看内嵌与外挂字幕及目标语言状态。
- **局部扫描**：选择影片文件夹，扫描后按需开始批量处理。
- **全局扫描**：扫描应用已获授权的存储位置；也可点击“扫描并处理”，扫描成功后自动开始处理。
- **手动搜索**：按片名、年份或 IMDb 编号查询，选择具体版本后再下载、核验和保存。
- **导入 SRT**：将自己找到的字幕交给程序识别、核验和保存。
- **搜索建议**：在有足够依据时，提供可尝试的片名、年份或 IMDb 搜索条件。
- **定时处理与日志**：设置每日处理时间，查看单片结果和导出处理记录。

在线字幕来源已接入 OpenSubtitles 和 SubDL，需配置自己的访问凭据。FN 版使用现成字幕，不运行本地 AI 翻译。搜索建议使用字幕站提供的片名、年份及影片编号信息。

## 第一次使用

公开安装包发布后，按对应安装说明完成部署，再依次操作：

1. 从飞牛桌面或手机内打开 SubFlow FN。
2. 在“设置”中选择目标语言，配置字幕来源，测试连接并保存。
3. 在“局部扫描”中选择影片文件夹，读取影片及已有字幕信息。
4. 点击“开始处理”，在影片详情和“运行日志”中查看结果。
5. 尚未补齐的影片，可继续手动搜索、使用具体搜索建议，或导入自己的 SRT。

详细步骤见 **[使用教程](docs/使用教程.md)**，常见疑问见 **[常见问题](docs/常见问题.md)**。

## 处理结果怎么看

“搜到候选”表示有可尝试的版本，仍需通过语言、格式和时间轴核验。已有文本字幕可在独立音频校准后作为其他字幕的时间参考，文本不限英文；需要下载参考字幕时，优先寻找英文。

程序先补初始缺失语言，再检查原有字幕。内嵌图片字幕因读取预算未能检查完时，会明确标注未完成校验，并按已有字幕保留。候选被拒绝、来源请求失败、身份不确定及资源停止等情况，可在详情或日志中查看。

搜索建议只提供下一步可尝试的操作，不等于已找到合格字幕；是否补齐以实际处理结果为准。
